# 产品概述与术语

## 1. 产品定位

多家族空间（Tenant）下的在线家谱协作平台：结构化维护人员、关系、事件与证据，提供家谱可视化与全维度家族统计，并对隐私与变更可追溯性提供细粒度控制。

目标用户：谱局编委、分支管理员、普通族人、只读访客（含分享链接场景）。

## 2. 范围边界（In Scope）

- Web 端为主（响应式布局，兼容桌面与平板；移动端以可用为准）。
- 单空间内多角色协作、审批流、审计与版本化谱书快照。
- 统计中心、自定义筛选报表、脱敏导出。
- GEDCOM 与表格导入导出、管理员级全量备份。

## 3. 非目标（Out of Scope，可后续扩展）

- 原生移动 App（除非另立项目）。
- 区块链存证、NFT。
- 自动从互联网爬取人物信息（合规与质量风险大，默认不做）。

## 4. 术语表

| 术语 | 定义 |
|------|------|
| 空间（Tenant） | 一个家族或修谱组织的隔离数据域；所有业务数据归属某一空间。 |
| 人员（Person） | 谱中个体，可绑定多个外部标识（如导入 ID）。 |
| 关系（Relationship） | 两人之间的有向或对称语义边，如亲子、配偶，含类型与元数据。 |
| 家庭单元（Family） | 可选的组合实体：一组父母与子女，用于展示与「户」统计。 |
| 事件（Event） | 带时间、地点、参与人、类型的事实记录。 |
| 房支 | 通常以某祖先为根的子树；用于权限范围与统计筛选。 |
| 字辈 | 世代用字规则，与代数、姓名用字校验相关。 |
| 来源（Citation） | 对陈述的证据引用：页码、档案、链接、摘录等。 |
| 修订工单 | 族人提交修改建议，经编委审核后合并或驳回。 |
| 谱书版本 | 某一时间点的只读快照，用于印刷或对外存档。 |
