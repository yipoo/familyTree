# 家谱系统 需求文档

> 版本：v0.1（草案）
> 日期：2026-04-30
> 状态：待评审

## 0. 项目概述

构建一个面向中国传统宗族的**多家族家谱管理与展示系统**，覆盖人物录入、关系维护、可视化浏览（树谱 / 吊线图 / 详细图 / 册谱）、协作编辑、统计与印刷输出。

**交付路线**

1. **第一阶段（当前）**：Web 端（响应式），桌面与手机浏览器同时可用
2. **第二阶段**：移动 App（iOS / Android）或微信小程序（二选一或并行，视用户分布）
3. 各端共用同一套后端 API 与数据模型

---

## 1. 名词与领域概念

| 术语 | 含义 |
|---|---|
| **家族（Family）** | 一个顶级宗族单位，如"丁氏"。系统支持多家族（多租户）共存 |
| **支系（Branch）** | 家族下按祖先 + 居住地形成的分支，例如"濉溪县南坪镇张牌坊新村—十七世训贤支" |
| **世代（Generation）** | 同辈在族谱中的层级，按数字递增（一世、二世……二十二世） |
| **字辈（Generation Name）** | 同一世男性命名中固定使用的一个字，如"良 / 允 / 贤 / 方 / 正 / 维 / 先 / 克"。常以括号标注于姓名后："宁（维）" |
| **吊线图** | 传统家谱形式，纵向树状图，仅显示主线人物与连线，附迁徙史 |
| **详细图** | 家庭单元表格：每行 = 一对夫妻 + 子女清单 + 备注 |
| **册谱** | 纸质家谱排版，包含吊线图、详细图、迁徙志等多种章节 |
| **树谱** | App / Web 中的交互式可视化节点图 |

---

## 2. 用户与角色

| 角色 | 权限 |
|---|---|
| **访客（Guest）** | 通过分享链接查看公开家谱，不能编辑 |
| **成员（Member）** | 浏览所属家族；可补录自己直系分支信息（待审核） |
| **管理员（Admin）** | 编辑全族数据、邀请成员、审核补录、导出印刷 |
| **族长 / 创建者（Owner）** | 家族全部权限，含转让、删除家族 |

一个用户可同时属于多个家族，扮演不同角色。

## 3. 功能需求

### 3.1 人物管理
- 字段：姓名、性别、头像、生卒年月、状态（在世 / 已故 / 失联）、备注
- 世代序数 + 字辈（新增人物时按所选父母自动推断世代，并提示该世字辈用字）
- 排行：长子 / 次子 / 长女 / 次女……（同一对父母下子女有序）
- 女性嫁入者历史上常仅记"X氏"，需兼容仅姓不名的录入

### 3.2 关系管理
- **婚配**：支持多段婚姻（原配 / 继配），含历史上的一夫多妻
- **亲子**：父—子、母—子分别建立，支持过继（生父母 ≠ 养父母）
- **招赘**：婚配关系可标记"入赘"。入赘时男方进入女方家族，其子女按**女方**家族的世代与字辈记录
- 关系上可附标记：已故、继妻、过继、入赘等

### 3.3 家庭单元（详细图的语义单元）
- 一行 = "夫 + 妻（含原继）+ 子女姓名与排行 + 备注"
- 自动从人物 + 关系数据生成，无需重复录入

### 3.4 地点与迁徙
- 现住地：省 / 市 / 县 / 镇 / 村（行政区划字典）
- 迁徙记录：年份、起讫地、原因（如"分居""塌陷""战乱"）
- 迁徙史**同时支持两种粒度**：
  - 支系级：挂在支系根节点，渲染时显示在支系标题侧栏
  - 个人级：挂在具体人物上，用于个人单独迁徙
- 渲染时两类迁徙记录按时间合并展示
- 支系标题示例：「濉溪县南坪镇张牌坊新村（南坪街西南）—十七世训贤」

### 3.5 家族与支系
- 创建家族：填写姓氏、始祖、**完整字辈表**（一次性录入，固定不再动态扩展）
- 支系树：以某祖先 + 地点划分，作为子图渲染与导出单位
- 字辈表修订：仅管理员可显式编辑（用于纠错），普通新增人物时不会触发字辈变更

### 3.6 浏览视图（核心功能）
四种视图必须**数据同源、可相互跳转**：

1. **树谱（交互式）**
   - 节点显示头像 + 姓名 + 性别色（男蓝 / 女粉）
   - 左侧固定"世代 + 字辈"轴
   - 支持横向 / 纵向滚动、缩放、定位到指定人
   - 顶部过滤：父系 / 母系 / **近亲（以当前人物为中心上下各 5 代）** / 全部
   - 顶部搜索：按姓名、字辈、地点

2. **吊线图（静态大图）**
   - 整族纵览或某支系子图
   - 纯文字 + 连线，左右两列世代标签夹住树
   - 旁附支系标题与迁徙史
   - 可导出为 PDF / 可分页打印

3. **详细图（表格）**
   - 列 = 世代，行 = 家庭单元
   - 含配偶姓名、子女数与排行、备注（已故 / 继妻）
   - 可导出为 PDF / Excel

4. **册谱（纸质版式预览）**
   - 组合"封面 + 序 + 字辈表 + 吊线图 + 详细图 + 迁徙志 + 索引"
   - **基于预设模板自动排版**（提供若干模板可选），无需人工设计
   - 输出 A3 / A4 PDF，可送印刷厂

### 3.7 编辑与历史
- 新增 / 修改 / 删除：人、关系、迁徙、字辈
- 操作历史与撤销
- 多人协作：成员补录进入审核队列，管理员合并

### 3.8 协作与分享
- 邀请成员（链接 / 二维码）
- 分享只读链接（可设密码 / 有效期）
- 印刷输出（册谱 PDF）

### 3.9 统计
- 总人数、男女比、各世人数、各支系人数
- 字辈分布、地域分布
- 在树谱底部以小卡片形式展示当前视图统计

### 3.10 信息架构（顶部 / 侧边导航）
- **树谱**：交互视图
- **册谱**：纸质版式与导出
- **发现**：跨家族 / 同姓 / 同字辈检索（远期）
- **我的**：账户、所属家族列表、邀请

## 4. 非功能需求

### 4.1 响应式与多端
- **当前版本：Web，自适应布局，覆盖**
  - 桌面（≥ 1280px）：左右分栏，左侧世代轴 + 主区树谱
  - 平板（768–1279px）：单栏，世代轴可折叠
  - 手机浏览器（< 768px）：参考 1.jpg 的移动端布局，底部 Tab 导航，世代轴竖排在左侧
- **二期端（App 为主，小程序为辅）**：
  - 原生 App（iOS / Android）：承载完整功能，含编辑与协作
  - 微信小程序：聚焦轻量浏览 + 分享传播，不含复杂编辑
  - 与 Web 共用同一后端 API
- 设计阶段即区分**展示组件**与**业务逻辑层**，便于多端复用

### 4.2 性能
- 单族 1000+ 人节点流畅渲染、缩放、平移
- 大图 PDF 导出支持分页拼接（A3 横版）

### 4.3 国际化与排版
- 中文优先，竖排世代标签
- 繁简兼容（如「紹福 / 绍福」）
- 后期可扩展英文界面

### 4.4 数据
- 导入：CSV / Excel 模板批量录入
- 导出：JSON、CSV、GEDCOM（国际通用家谱格式，远期）
- 多租户隔离：家族数据严格按 `family_id` 隔离

### 4.5 安全与隐私
- 在世人物默认仅家族内可见，分享链接可选脱敏（隐去生辰、住址）
- 操作日志可追溯

### 4.6 可访问性
- 键盘可达
- 头像缺省占位、低带宽下文本优先

## 6. 范围与非目标

**第一阶段范围（MVP）**
- 单家族创建、人物 / 关系 / 字辈录入
- 树谱（Web 响应式）+ 吊线图导出 + 详细图导出
- 基础协作（邀请、只读分享）

**非目标（明确不做）**
- DNA / 基因关系
- 跨家族联姻自动建链
- 实时音视频族会
- AI 自动从老家谱图片识别录入（远期可探索）

## 7. 关键决策（已确认）

1. **字辈表固定**：家族创建时一次性录入完整字辈序列，后续不可动态扩展（如需修订需管理员显式编辑）。新增人物时按其所在世自动取对应字辈
2. **支持招赘**：婚配关系需标记"入赘"；入赘男方的子女归入女方家族世系，世代/字辈按女方家族计算
3. **"近亲"= 5 代以内**：以当前选定人物为中心，向上向下各延伸 5 代（含本人），父母旁支同样按 5 代血缘距离过滤
4. **迁徙史：个人级与支系级均支持**
   - 支系级：作为支系根节点的属性（如"十七世训贤支 1927 年迁张牌坊"）
   - 个人级：挂在某具体人物上（个人单独迁徙）
   - 渲染时合并展示
5. **册谱用模板**：提供若干预设版式模板（封面、字辈表页、吊线图页、详细图页、迁徙志页），用户选择模板后系统自动排版，无需设计师介入
6. **二期端：App 为主，小程序为辅**
   - App（iOS / Android）承载完整功能
   - 小程序聚焦轻量浏览 + 分享（不含复杂编辑）
   - Web 与两端共用后端 API
