# 功能需求规格（全量）

本文档描述「一步到位」功能范围，实现时可按依赖顺序排期，但产品行为以本文为准。

## 1. 用户与组织

### 1.1 账户

- 注册、登录、登出；邮箱/手机（可选其一为主）；第三方 OAuth（可选）。
- 多因素认证（MFA）；密码找回；会话列表与撤销会话。
- 用户资料：头像、显示名；与谱内人员的绑定申请与审核。

### 1.2 家族空间

- 创建/归档空间；空间名称、徽标、简介、默认语言与时区。
- 空间级配置：默认隐私策略、字辈功能开关、导入覆盖策略。

### 1.3 角色（可组合）

- 超级管理员、谱局总编、分支管理员、编委、族人、访客。
- 权限维度：对象类型 × 操作 × 数据范围（全谱/房支/子树）× 字段级（如联系方式）× 时间限制（临时授权）。

### 1.4 协作流程

- 邀请链接/邮件，附带角色与范围。
- 修订工单：提交 → 审阅 → 通过合并 / 驳回（理由）→ 通知。
- 敏感操作：删除人员、合并人员、批量导入覆盖需二次确认与审计记录。

## 2. 核心数据：人员

- 谱名、学名、字、号、乳名、别名；性别；存殁。
- 生卒：公历/农历、精度（年/月/日）、地点（结构化层级）。
- 民族、国籍、学历、职业（字典项）、宗教（可选）。
- 字辈、排行、房支标签、自定义标签。
- 传记（富文本）；按字段或整块设置隐私级别。
- 在世人员默认更严展示策略（可配置为「仅关系可见」等）。

## 3. 关系与家庭

- 关系类型：生父母、养父母、继父母、监护人、配偶、伴侣、子女序位等。
- 多段婚姻；结婚/离婚日期与地点；婚姻状态。
- 血缘与法律关系标记；存疑关系标记与备注。
- 家庭单元（可选）：父母 + 子女组合，用于列表与统计。

## 4. 事件与时间轴

- 事件类型字典：出生、入学、工作、迁徙、结婚、离异、逝世、祭祀等。
- 事件字段：时间（多历法）、地点、参与人、描述、来源、附件、可见范围。
- 视图：个人时间轴、家族时间轴（筛选房支/年代）。

## 5. 字辈与谱例

- 字辈谱维护；辈分与代数映射；姓名用字与字辈一致性提示。
- 谱例说明：排行书写、异体字、避讳（展示层）。

## 6. 地点与迁徙

- 地点库去重与别名；坐标（可选）；迁徙边（从 A 到 B）供地图与流向统计。

## 7. 媒体与证据

- 相册；照片/扫描件/音视频；关联人物或事件。
- 来源与摘录；可信度等级；版权与使用范围声明。

## 8. 数据质量与治理

- 环路检测（非法关系环）、孤儿节点报告。
- 重复人员候选队列与合并向导（字段级合并策略）。
- 误合并拆分（管理员）；全链路审计。
- 缺失字段统计与待补全列表。

## 9. 展示与交互

- 家谱树：多方向布局、搜索定位、路径高亮、子树折叠、大谱懒加载。
- 列表/表格：排序、筛选、保存为智能列表。
- 搜索：全文、拼音、组合条件。
- 评论与讨论：threaded、@ 提醒、关联工单。
- 通知中心：站内 + 邮件/短信/Webhook（可选）。

## 10. 统计与报表

- 仪表盘：总人数、在世/故、男女、代数跨度、完整度得分、最近更新。
- 结构：分代人数、房支对比、婚姻段数、子女数分布等（有数据则展示）。
- 生命周期：出生年代分布、寿命分布、结婚年龄、代际间隔。
- 地理：籍贯/现居 Top、热力、迁徙流向。
- 字辈：各辈人数、交叉表、合规率。
- 数据质量面板：解释当前筛选样本与排除原因。
- 自定义报表：保存维度组合；导出 PDF/Excel/图表。

## 11. 谱书版本

- 冻结快照为谱书版本；与线上编辑分离；支持只读浏览与导出。

## 12. 导入导出与 API

- GEDCOM 导入/导出与字段丢失报告。
- Excel/CSV 模板导入、映射向导、校验预览。
- 增量更新（外部 ID）；REST API 与 API Key；Webhook（人物变更推送，可选）。

## 13. 管理后台

- 成员与角色、分支授权矩阵、字典管理、空间参数、存储与 API 用量（若运营需要）。

## 14. 多语言与无障碍

- UI 多语言；关键谱文字段可双语。
- 键盘导航、对比度；图表提供数据表替代视图。

## 15. 验收原则（摘要）

- 权限拒绝时不得泄露受保护字段（含 API 与导出）。
- 合并/删除/导入等操作可追溯且在审计日志可查。
- 统计结果页须展示筛选条件与数据完整度提示，避免误读。
